# Assignment 11: Natural Language Processing (NLP)

**Objective:** Apply NLP preprocessing (stopword removal, tokenization, TF-IDF) for text projects.

---

## Dataset

The dataset contains customer information with the following columns:

- CustomerID
- Age
- Gender
- Tenure
- Usage Frequency
- Support Calls
- Payment Delay
- Subscription Type
- Contract Length
- Total Spend
- Last Interaction
- Churn

**Note:** For NLP demonstration, a `Customer_Feedback` column (dummy text) is added.

---

## NLP Pipeline

**Steps:**

1. **Preprocessing:**
   - Convert text to lowercase
   - Tokenize text (split words)
   - Remove stopwords and non-alphabetic words

2. **TF-IDF Vectorization:**
   - Transform text into numeric TF-IDF features
   - Save TF-IDF matrix and feature names for future use

---

## Milestone Achieved

- NLP preprocessing pipeline ready for text-based projects.
- TF-IDF features prepared for future modeling and analysis.
